# Shards of the Crimson Moon — asset manifest

Generated by `tools/make_sprites.py` (and `tools/make_wordmark.py` for the wordmark).
All sprites are nearest-neighbor pixel art at 1:1 game pixels (engine scales 4×).
**No `#FFFFFF`.** Brightest value is `#FFF6DE`. Transparent RGBA backgrounds on sprites.
Crimson is accent-only. Gold reads as light (edge highlights).

### Tileset grid (all `tiles-*.png`)

Each tileset is **8 columns × 4 rows** of **16×16** cells → **128×64**.

| Index | Row | Col | Role |
|---|---|---|---|
| 0–3 | 0 | 0–3 | Ground fill variants |
| 4–5 | 0 | 4–5 | Terrace top |
| 6–7 | 0 | 6–7 | Terrace body |
| 8–9 | 1 | 0–1 | Wall / pillar |
| 10–11 | 1 | 2–3 | Rubble |
| 12–13 | 1 | 4–5 | Deco (urn / tablet) |
| 14–15 | 1 | 6–7 | Empty / transparent |
| 16 | 2 | 0 | Altar lit (Order gold / Cult ember / Saffrika jungle shrine) |
| 17 | 2 | 1 | Hazard: ember (cult/vespera/deep/deep-lairs) or bone spike (plains/aurelion/saffrika/sakura) |
| 18–19 | 2 | 2–3 | Door / entrance |
| 20–21 | 2 | 4–5 | Stairs step |
| 22 | 2 | 6 | Extra hazard / river / ice / empty |
| 23 | 2 | 7 | Extra pillar |
| 24–27 | 3 | 0–3 | Accent props (torch, banner, crystal, leaf/ice) |
| 28–29 | 3 | 4–5 | Shadow edge |
| 30–31 | 3 | 6–7 | Highlight edge |

**Index 17 hazard map:** bone spike → `plains`, `aurelion`, `saffrika`, `sakura`. Ember floor → `cult-hideout`, `vespera`, `deep`, `deep-lairs`.

## Controller glyphs (shards-v7)

Generated by `tools/make_pad_glyphs.py` (own generator; it refuses to write any file outside
its own list). Final pixel art, 1:1 game pixels, drawn inline in text by the engine for
`{A}`-style tokens while the gamepad is the active device.
Palette: face buttons in muted Xbox colours tuned to the game: A green `#2E4A25 #4F7A3A #86AE5E`
and X steel blue `#22384E #3F6688 #7898B8` (new, `data/palettes.js` -> `pad`), B on the cult
crimson ramp `#8B1E2D #B42334 #E0604A`, Y on the Order gold ramp `#8A6E1F #C9A227 #E8C547`;
shoulders, Start, View, stick and D-pad on the bone ramp `#6B6458 #B8AA92 #E8DCC8`; legends in
panel Obsidian `#0B0A09`; 1 px Void `#050404` drop shadow. No `#FFFFFF`; nothing brighter than `#FFF6DE`.
