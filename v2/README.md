# Shards of the Crimson Moon

Browser build (PWA) of *Shards of the Crimson Moon*. Play at
https://bourgeoisblevins.github.io/shards-of-the-crimson-moon/

Works with keyboard, gamepad, or touch (landscape). On iPhone, use Share > Add to Home Screen for full screen.

This is **v2**: 480×270, with all-new 16-bit-style art. Saves from v1 carry over on the first launch.
The original v1 build is archived at https://bourgeoisblevins.github.io/shards-of-the-crimson-moon/v1/
